# Snehil Raj — Official Portfolio

Responsive static portfolio with professional portrait, LinkedIn/GitHub/Instagram/Facebook links, SEO metadata, Person JSON-LD, sitemap, robots.txt and favicon.

## IMPORTANT: publish as a GitHub user site (avoids the previous 404)

1. Open https://github.com/new while signed in as `snehilraj1124-ship-it`.
2. Repository name MUST be exactly `snehilraj1124-ship-it.github.io` (public).
3. Create repository. Upload the CONTENTS of this folder (`index.html`, `assets/`, `robots.txt`, `sitemap.xml`, `favicon.svg`) directly into the repository root. Do not upload the parent folder as a nested folder.
4. Open repository Settings → Pages. Under Build and deployment, select **Deploy from a branch**, branch **main**, folder **/(root)**, then Save.
5. Wait for the Pages deployment to finish. The live URL will be https://snehilraj1124-ship-it.github.io/ .

If GitHub shows a Pages build error, open the Actions tab and inspect the latest Pages workflow. Ensure `index.html` is at repository root and repository is public.

## Google indexing
After the live URL works, add it in Google Search Console, verify ownership, submit `https://snehilraj1124-ship-it.github.io/sitemap.xml`, then inspect the homepage and request indexing. Google decides when/if it appears; ranking for a common name and a knowledge panel cannot be guaranteed.
